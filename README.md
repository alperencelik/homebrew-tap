# Homebrew tap

```sh
brew install alperencelik/tap/ctrlplane
```

| Cask | What |
|---|---|
| `ctrlplane` | CLI and kubectl plugin for [ctrlplane](https://ctrlplane.run) ([source](https://github.com/alperencelik/ctrlplane-cli)) |

The casks are written by each project's release (GoReleaser); don't edit them by hand.
